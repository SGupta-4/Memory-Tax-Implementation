# Definition of done

A change counts as done only when these commands produce these outputs. Paste the real output into its `BUGS.md` entry.

These commands describe the repo as planned. Commands marked with a phase don't exist until that phase. If a command's real output format differs, record the correct form here, but don't weaken what it checks.

## Universal gate: every change

Run each command through `uv run` (for example `uv run mypy src`), so the locked environment is used. Recorded 2026-11-02.

| # | Command | Expected |
| --- | --- | --- |
| 1 | `ruff check . && ruff format --check .` | `All checks passed!` and `N files already formatted`; exit 0 |
| 2 | `mypy src` | `Success: no issues found`; exit 0 |
| 3 | `pytest -q -m "not gpu"` | `0 failed`; exit 0 |
| 4 | `python scripts/check_repo.py` | `OK`; exit 0 |
| 5 | `memtax smoke --config configs/fixture.yaml` | `smoke OK: 4 questions, identity holds`; exit 0, with no network or GPU |
| 6 | `git status --short` | Only intended files; no data, secrets, or `runs/` |

Check 4 fails if any of these is true:

- A `src/` module lacks `Purpose:`, `Called by:`, or `Assumes:`.
- A commit changes `src/` without changing `FLOW.md` or `BUGS.md`.
- A new dependency has no `D-NNN` that mentions it.
- A `Currently modifying` entry names a file that doesn't exist.

## Phase gates

Record each gate's output, then tag it.

| Gate | Command | Expected | Tag |
| --- | --- | --- | --- |
| G0 | `memtax audit --bench longmemeval_s` | `simplemem=60.2 rag1=70.2 rag2=72.2 tax=18.2±0.1 benefit=8.2±0.1 n=500`. Real form: first line prints values without `±`, two CI lines follow, and the last line is `G0 PASS`, with exit 0 ([D-025](DECISION.md)) | `phase-0-pass` |
| G1 | `memtax gate 1` | Chunks ≥99%; judge ≥90%; RAG within ±3 of 70.2; agreement ≥85%; `no_think=true`; failures ≤1%; repeat ≥95% | `phase-1-pass` |
| G2 | `memtax gate 2` | At least 7 of 10 builds match; store size within ±20%; replay within ±3 of 60.2; agreement ≥85% | `phase-2-pass` |
| G3 | `memtax gate 3` | H2 has CI and McNemar p; held-out run count = 1, or deviations logged; commit is at or after `prereg-h2` | `phase-3-pass` |
| G4 | `memtax gate 4` | Two generations hash equal; every question traces to evidence; CIs by patient | `phase-4-pass` |
| G5 | Clean Kaggle CPU notebook: `make reproduce` | All report tables match, with no GPU | `v1.0.0` |

G1 and G2 thresholds are set before their runs. Don't change them after seeing results.

## Before claiming a result

- [ ] The run has a manifest, with a clean commit.
- [ ] The result is paired against one-round RAG, with a CI.
- [ ] The table in the report was generated by `make reproduce`.
- [ ] Differences from the paper are written down.
- [ ] Null and negative results appear too.
